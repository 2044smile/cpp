# 4.4 auto 키워드와 자료형 추론 (Type Inference)

## 형 추론

- 파라미터 타입에는 auto를 사용할 수 없다
- auto는 반드시 초기화와 함께 사용해야 한다 (초기화 없으면 컴파일 에러)
- 타입은 컴파일 타임에 확정되며, 이후 다른 타입으로 변경 불가

```cpp
auto a = 123;       // int
auto b = 123.0;     // double
auto c = 123.0f;    // float
auto d = true;      // bool
auto e = 'A';       // char

auto x;             // 컴파일 에러 - 초기화 필요
```

## 코드 가독성

후행 반환 타입(trailing return type): `->` 뒤에 반환 타입을 명시

```cpp
auto add(int x, int y) -> int;
auto add(int x, int y) -> double;

int     add(int x, int y);
double  add(int x, int y);
```

반환 타입이 매개변수에 의존할 때 후행 반환 타입이 필수적으로 사용된다

## Template

- `template<typename T, typename U>` - "T, U라는 타입을 나중에 결정하겠다"는 선언
- `decltype(x + y)` - "x + y의 결과 타입이 뭔지 컴파일러야 알아서 추론해줘"

```cpp
// 앞에 쓰면 x, y가 아직 선언 전이라 사용 불가
template<typename T, typename U>    //* T, U라는 타입을 나중에 결정하겠다는 선언
auto add(T x, U y) -> decltype(x + y)
{
    return x + y;
}
```

## Python과의 비교

```python
# Python: 런타임에 타입 결정, 이후 변경 가능
a = 123
a = "hello"  # OK

def add(x: int, y: int) -> int:  # -> 문법 동일
    return x + y
```

```cpp
// C++: 컴파일 타임에 타입 확정, 이후 변경 불가
auto a = 123;
a = "hello";  // 에러! a는 이미 int로 확정됨

auto add(int x, int y) -> int  // -> 문법 동일
{
    return x + y;
}
```
