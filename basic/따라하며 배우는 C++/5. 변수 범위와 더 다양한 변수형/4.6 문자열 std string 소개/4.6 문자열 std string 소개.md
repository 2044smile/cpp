# 4.6 문자열 `std::string` 소개

---

## 들어가며

여러분, 프로그램을 작성하다 보면 숫자뿐 아니라 **이름, 주소, 문장** 같은 텍스트 데이터를 다뤄야 할 때가 매우 많습니다.  
C++에서는 이러한 문자열을 다루는 두 가지 방법이 있습니다.

- **C 스타일 문자열** : `char` 배열을 직접 다루는 고전적인 방법
- **`std::string`** : C++ 표준 라이브러리가 제공하는 현대적이고 안전한 방법

오늘은 `std::string`을 중심으로, 왜 이것이 더 편리하고 강력한지 함께 알아보겠습니다.

---

## 1. 헤더 파일 포함

```cpp
#include <iostream>
#include <string>
#include <limits>
```

| 헤더 | 역할 |
|---|---|
| `<iostream>` | `cin`, `cout` 입출력 |
| `<string>` | `std::string` 클래스 사용 |
| `<limits>` | `std::numeric_limits` — 자료형의 최대값 등을 조회 |

> `<string>` 을 빠뜨리면 컴파일 오류가 발생합니다. 잊지 마세요!

---

## 2. 문자열 선언과 초기화

```cpp
const char my_strs[] = "Hello, World";      // C 스타일: char 배열
const string my_hello_1 = "Hello, World";   // 대입 초기화
const string my_hello_2 { "Hello, World" }; // 중괄호 초기화 (권장)
```

### C 스타일 vs `std::string` 비교

| 구분 | `char` 배열 | `std::string` |
|---|---|---|
| 선언 | `char s[] = "abc";` | `string s = "abc";` |
| 길이 변경 | 불가 (고정 크기) | 자유롭게 변경 가능 |
| 연결(`+`) | 직접 불가 | `s1 + s2` 로 간단하게 |
| 안전성 | 버퍼 오버플로우 위험 | 안전하게 관리됨 |

> C 스타일 배열은 직접 메모리를 다루므로 위험합니다. 특별한 이유가 없다면 `std::string`을 사용하는 것이 현명한 선택입니다.

---

## 3. 문자열은 정수를 직접 받을 수 없다

```cpp
// string my_ID = 123;  // 컴파일 오류!
string my_ID = "123";   // 올바른 방법
```

`std::string`은 **정수를 문자열로 암시적으로 변환하는 방법이 없습니다.**  
정수를 문자열로 바꾸고 싶다면 `std::to_string()` 함수를 사용하세요.

```cpp
int num = 123;
string s = std::to_string(num);  // "123"
```

## 4. 문자열 입력 — `cin` vs `getline`

### `cin >>` 의 한계

```cpp
string name;
cin >> name;  // "Jack Jack" 입력 시 "Jack" 만 읽힘
```

`cin >>`은 **공백(스페이스, 탭)을 구분자로 사용**하기 때문에, 빈칸이 포함된 문자열을 한 번에 읽을 수 없습니다.  
나머지 입력(" Jack\n")은 버퍼에 남아 다음 `cin`에서 읽혀 버립니다.

### `std::getline` 사용

```cpp
string name;
std::getline(std::cin, name);  // 엔터를 칠 때까지 전부 읽음
```

`getline`은 **줄바꿈 문자(`\n`)가 나올 때까지** 모든 문자를 읽어들입니다.  
빈칸이 포함된 이름도 안전하게 읽을 수 있습니다.

---

## 5. 정수 입력 후 문자열 입력 — 버퍼 문제와 해결

```cpp
int age_1;
cin >> age_1;
```

`cin >> age_1`을 실행하면 숫자는 읽히지만, **입력 버퍼에 줄바꿈 문자(`\n`)가 남습니다.**  
그 상태에서 바로 `getline`을 호출하면, 남은 `\n`을 빈 줄로 인식하고 빈 문자열을 반환해버립니다.

### 해결 방법 — `cin.ignore()`

```cpp
// 방법 1: 간단하게 32767자까지 무시
std::cin.ignore(32767, '\n');

// 방법 2: 권장 — 스트림 크기 한계까지 정확하게 처리
std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
```

| 방법 | 설명 |
|---|---|
| `ignore(32767, '\n')` | 최대 32767개 문자를 `\n`이 나올 때까지 무시 |
| `ignore(numeric_limits<streamsize>::max(), '\n')` | 스트림이 가질 수 있는 최대 크기만큼 무시 (더 안전) |

> `numeric_limits<streamsize>::max()`는 "이 시스템에서 스트림이 가질 수 있는 최대 크기"를 의미합니다. 매직 넘버인 `32767` 대신 이 방식을 사용하는 것이 이식성(portability) 측면에서 훨씬 좋습니다.

### 올바른 정수 + 문자열 입력 예시

```cpp
cout << "Your age ? : ";
int age_1;
cin >> age_1;

std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');  // 버퍼 비우기

cout << "Your name ? : ";
string name_1;
std::getline(std::cin, name_1);

cout << name_1 << " " << age_1 << endl;
```

## 6. 문자열 연결 (Concatenation)

```cpp
string a("Hello, ");
string b("World ");
string hw = a + b;   // "Hello, World "
hw += "I'm Good";    // "Hello, World I'm Good"

cout << hw << endl;
```

`std::string`은 `+` 연산자와 `+=` 연산자를 지원하여 **문자열을 쉽게 이어 붙일 수 있습니다.**  
C 스타일 배열에서는 `strcat()` 같은 함수를 사용해야 하고 버퍼 크기도 직접 관리해야 하지만, `std::string`은 이 모든 것을 자동으로 처리해줍니다.

## 7. 문자열 길이 — `.length()`

```cpp
string c("Hello, World");
cout << c.length() << endl;  // 12 출력
```

`.length()` 는 문자열에 포함된 문자 수를 반환합니다. `.size()`와 동일한 결과를 반환합니다.

```cpp
c.length();  // 12
c.size();    // 12 (동일)
```

> **참고** : 반환 타입은 `size_t` (부호 없는 정수)입니다. 음수와 비교하거나 뺄셈을 할 때 주의하세요.

## 8. 버퍼란

> 키보드에서 입력한 문자들은 바로 프로그램으로 오는 게 아니라 중간 저장소(버퍼)를 거친다

```cpp
버퍼: ['2' | '5' | '\n']
cin >> age_1; // 실행 시
// 1. 앞의 공백/개행 문자 건너뜀
// 2. 숫자 25 읽어서 age_1에 저장
// 3. `\n`은 읽지 않고 버퍼에 그대로 남김
버퍼: ['\n']
getline(cin, age_1) // ignore 없이 바로 호출
// getline은 '\n'을 만날 때까지 읽는데, 버퍼에 '\n' 이 이미 있으니 즉시 반환
```

### cin.ignore()가 하는 일

`std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');`

버퍼에서 `\n`이 나올 때까지 문자를 전부 버립니다. 즉, "현재 줄의 나머지를 버리는 함수"

```
버퍼: [ '\n' ]
        ↑
  ignore가 '\n' 을 만나면 그것도 포함해서 버림

버퍼: [  비어있음  ]
```
이후 getline 호출 시 새로운 입력을 기다립니다.

---

## 핵심 정리

| 개념 | 핵심 내용 |
|---|---|
| 선언 | `string s = "text";` 또는 `string s { "text" };` |
| 정수 변환 | 암시적 변환 불가 → `std::to_string()` 사용 |
| 공백 포함 입력 | `getline(cin, s)` 사용 |
| 버퍼 정리 | `cin.ignore(numeric_limits<streamsize>::max(), '\n')` |
| 연결 | `s1 + s2`, `s1 += s2` |
| 길이 | `s.length()` 또는 `s.size()` |

---

## 마치며

`std::string`은 C++이 제공하는 가장 편리한 도구 중 하나입니다.  
단순히 텍스트를 저장하는 것을 넘어, 비교(`==`, `<`), 검색(`.find()`), 잘라내기(`.substr()`) 등 다양한 기능을 제공합니다.  
앞으로 문자열을 다뤄야 할 때는 항상 `std::string`을 먼저 떠올리는 습관을 들이세요.
