# 4.7 열거형 enumerated types

## 열거형의 값도 전역으로 작동해서 중복 데이터가 있으면 안된다

> 이를 방지하기 위해 enum class 가 존재하고 C++11 이 후 버전에서 지원한다

```cpp
enum Color
{
    COLOR_BLACK,
    TARGET, // 충돌
};

enum Feeling
{
    HAPPY,
    TARGET, // 충돌 → 컴파일 에러
};
```

---

## enum class (scoped enum) — 꼭 알아야 함

일반 `enum`의 이름 충돌 문제를 해결한 C++11 문법

```cpp
enum class WeaponType { SWORD, HAMMER, BOW };
enum class Color      { RED, BLUE, GREEN };

WeaponType w = WeaponType::SWORD;  // 반드시 WeaponType:: 접두사 필요
Color c      = Color::RED;

// w = 0;           // 에러: int 직접 대입 불가
// w = Color::RED;  // 에러: 다른 enum class 대입 불가
```

| | `enum` | `enum class` |
|---|---|---|
| 이름 충돌 | 발생 가능 | 없음 (:: 접두사) |
| int 암묵적 변환 | 허용 | 불허 |
| 타입 안전성 | 낮음 | 높음 |
| C++ 버전 | C++98~ | C++11~ |

## switch + enum — if-else보다 이걸 써라

```cpp
int computeDamage(WeaponType weapon) {
    switch (weapon) {
        case WeaponType::SWORD:  return 1;
        case WeaponType::HAMMER: return 2;
        case WeaponType::BOW:    return 3;
    }
    return 0;
}
```

`switch`를 쓰면 컴파일러가 "enum 값 중 빠진 case가 있다"고 경고해줘서 실수를 줄일 수 있다

## struct + enum — OOP의 시작점

enum을 struct 안에 넣으면 **객체가 상태를 가지는** 구조가 된다. 이게 나중에 배울 `class`의 기초

```cpp
struct Player {
    std::string name;
    WeaponType  weapon;  // 상태를 enum으로 표현
    int         hp;
};

Player p1 = {"홍길동", WeaponType::HAMMER, 100};
```

파이썬으로 비유하면:

```python
from enum import Enum

class WeaponType(Enum):
    SWORD  = 0
    HAMMER = 1
    BOW    = 2

class Player:
    def __init__(self, name, weapon, hp):
        self.name   = name
        self.weapon = weapon
        self.hp     = hp

p1 = Player("홍길동", WeaponType.HAMMER, 100)
```

C++의 `enum class` = Python의 `class WeaponType(Enum)`과 거의 동일한 개념
