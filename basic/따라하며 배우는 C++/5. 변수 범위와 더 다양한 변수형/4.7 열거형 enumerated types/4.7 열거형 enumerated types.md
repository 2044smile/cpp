# 4.7 열거형 enumerated types

## 열거형의 값도 전역으로 작동해서 중복 데이터가 있으면 안된다

> 이를 방지하기 위해 enum class 가 존재하고 C++11 이 후 버전에서 지원한다

```cpp
enum Color
{
    COLOR_BLACK,
    TARGET, // 충돌
};

enum Feeling
{
    HAPPY,
    TARGET, // 충돌 → 컴파일 에러
};
```

---

## enum class (scoped enum) — 꼭 알아야 함

일반 `enum`의 이름 충돌 문제를 해결한 C++11 문법

```cpp
enum class WeaponType { SWORD, HAMMER, BOW };
enum class Color      { RED, BLUE, GREEN };

WeaponType w = WeaponType::SWORD;  // 반드시 WeaponType:: 접두사 필요
Color c      = Color::RED;

// w = 0;           // 에러: int 직접 대입 불가
// w = Color::RED;  // 에러: 다른 enum class 대입 불가
```

| | `enum` | `enum class` |
|---|---|---|
| 이름 충돌 | 발생 가능 | 없음 (:: 접두사) |
| int 암묵적 변환 | 허용 | 불허 |
| 타입 안전성 | 낮음 | 높음 |
| C++ 버전 | C++98~ | C++11~ |

## switch + enum — if-else보다 이걸 써라

```cpp
int computeDamage(WeaponType weapon) {
    switch (weapon) {
        case WeaponType::SWORD:  return 1;
        case WeaponType::HAMMER: return 2;
        case WeaponType::BOW:    return 3;
    }
    return 0;
}
```

`switch`를 쓰면 컴파일러가 "enum 값 중 빠진 case가 있다"고 경고해줘서 실수를 줄일 수 있다

## struct + enum — OOP의 시작점

enum을 struct 안에 넣으면 **객체가 상태를 가지는** 구조가 된다. 이게 나중에 배울 `class`의 기초

```cpp
struct Player {
    std::string name;
    WeaponType  weapon;  // 상태를 enum으로 표현
    int         hp;
};

Player p1 = {"홍길동", WeaponType::HAMMER, 100};
```

파이썬으로 비유하면:

```python
from enum import Enum

class WeaponType(Enum):
    SWORD  = 0
    HAMMER = 1
    BOW    = 2

class Player:
    def __init__(self, name, weapon, hp):
        self.name   = name
        self.weapon = weapon
        self.hp     = hp

p1 = Player("홍길동", WeaponType.HAMMER, 100)
```

C++의 `enum class` = Python의 `class WeaponType(Enum)`과 거의 동일한 개념

## OOP(객체지향 프로그래밍)은 왜 필요할까?

모든 프로그램은 `데이터 + 로직` 으로 작동이 된다. 즉 객체지향 없이도 구현할 수 있다.

하지만 코드가 급격하게 늘어난ㄷ나면 `객체지향 프로그래밍` 을 하지 않았더라면 아무리 파일을 분리해서 관리한다고 하여도 관리를 하는 것에 대한 한계가 있을 것이다.

### 절차지향적

> 함수의 사용이 한정된다는 단점

일단 `HealPlayer` 라는 함수가 `Knight` 라는 타입만 받아서 함수를 실행할 수 있다는 점이다. 만약 다른 직업이 생긴다면 함수를 따로 만들어줘야 하는 번거로움이 생긴다

```cpp
#include <iostream>
using namespace std;

struct  Knight
{
    int hp;
    int attack;
    int defence;
}

void HealPlayer(Knight& a, int value)
{
    a.hp += value;
}

int main()
{
    Knight k1;
    k1.hp = 100;
    k1.attack = 10;
    k1.defence = 3;

    HealPlayer(k1, 100)
    return 0;
}
```

### 객체지향적

> 객체란 메모리를 할당 받아 사용되는 모든 데이터 즉, 우리가 사용했던 `변수, 구조체, 함수` 등이 전부 객체라고 할 수 있다 추가로 객체지향에서 `객체`는 대부분 `클래스의 인스턴스` 이다.

#### 클래스 

- 객체를 만들어내기 위한 툴, 설계도
- 변수와 메서드의 집합

#### 객체(Object)

- 개념
    - 구현할 대상
    - 클래스에 선언된 모양 그대로 생성된 실체
- 특징
    - `클래스의 인스턴스` 라고 불림
        - 객체는 모든 인스턴스를 대표하는 포괄적인 의미
        - 객체지향 관점에서 클래스의 타입으로 선언되었을 때 `객체` 라고 부름

#### 인스턴스(Instance)

- 개념
    - 설계도를 바탕으로 구현된 구체적인 설계
        - 즉, 객체를 실체화 하면 그것을 `인스턴스`라고 부른다
        - 실체화된 인스턴스는 메모리에 할당된다
- 특징
    - 인스턴스는 객체에 포함된다고 볼 수 있음
    - 객체지향 관점에서 객체가 메모리에 할당되어 실제 사용될 때 `인스턴스`라고 부른다
    - 객체는 클래스의 인스턴스다
