# 4.10 구조체 struct

## 구조체란?

서로 관련된 데이터를 하나로 묶어서 관리하는 **사용자 정의 타입**이다.

```cpp
// 구조체 없이
double height;
float  weight;
int    age;
string name;

// 구조체로 묶으면
struct Person {
    double height;
    float  weight;
    int    age;
    string name;
};
```

관련 데이터가 하나의 단위로 묶이기 때문에 **함수에 넘기거나 배열로 관리하기가 훨씬 쉬워진다.**

---

## 초기화 방법

```cpp
Person me{172.6, 70.9f, 31, "Tim Dekay"};    // 중괄호 초기화 (C++11, 권장)
Person mom;                                  // 기본 초기화 (멤버값은 미정)
mom.age = 50;                                // 멤버 접근은 . 연산자
```

---

## 구조체 안에 함수 (메서드)

```cpp
struct Person {
    double height;
    string name;

    void print() {
        cout << name << " " << height << endl;
    }
};

Person me{172.6, 0.0f, 31, "Tim"};
me.print();  // 객체가 직접 동작
```

데이터와 기능을 함께 묶는 순간, 이것이 **객체지향의 시작**이다.

---

## struct vs class

딱 하나의 차이만 있다: **기본 접근 권한**

```cpp
struct Person { int age; };  // 기본 public  → 외부 접근 가능
class  Person { int age; };  // 기본 private → 외부 접근 불가
```

관행적 구분:
- 데이터만 담는 단순 묶음 → `struct`
- 데이터 + 기능 + 접근 제어 → `class`

---

## 참조로 전달 — 꼭 알아야 할 핵심

```cpp
// 값 전달: Person 전체가 복사됨 (비효율)
void print(Person p) { ... }

// 참조 전달: 주소만 넘김 (효율적)
void print(const Person& p) { ... }
```

`Person`이 커질수록 복사 비용이 커진다. 수정할 필요가 없으면 `const &`로 넘기는 것이 기본이다.

```cpp
struct BigData {
    double values[1000];  // 8000바이트
};

void process(BigData data)        // 매번 8000바이트 복사 → 비효율
void process(const BigData& data) // 주소(8바이트)만 전달 → 효율적
```

## 구조체 중첩 — 실무에서 자주 쓰임

```cpp
struct Address {
    string city;
    string street;
};

struct Person {
    string  name;
    int     age;
    Address address;  // 구조체 안에 구조체
};

Person p{"Tim", 31, {"Seoul", "Gangnam-daero"}};
cout << p.address.city << endl;  // Seoul
```

## 구조체 배열 — 여러 객체 관리

```cpp
Person team[3] = {
    {172.6, 70.9f, 31, "Tim"},
    {165.0, 55.0f, 28, "Alice"},
    {180.0, 80.0f, 35, "Bob"},
};

for (int i = 0; i < 3; i++) {
    team[i].print();
}
```

---

## 포인터와 구조체 — `->` 연산자

나중에 `new`로 동적 할당할 때 반드시 마주치게 된다.

```cpp
Person* p = new Person{172.6, 70.9f, 31, "Tim"};

p->print();    // 포인터일 때는 -> 사용
(*p).print();  // 위와 동일하지만 가독성이 떨어짐

delete p;  // Heap 메모리는 반드시 직접 해제
```

| 변수 종류 | 멤버 접근 |
|---|---|
| `Person p` (일반 변수) | `p.name` |
| `Person* p` (포인터) | `p->name` |

## Python과의 비교

```python
# Python
class Person:
    def __init__(self, height, weight, age, name):
        self.height = height
        self.weight = weight
        self.age    = age
        self.name   = name

    def print_person(self):
        print(self.name, self.age)

me = Person(172.6, 70.9, 31, "Tim")
me.print_person()
```

C++의 `struct` (메서드 포함) = Python의 `class`와 거의 동일한 개념이다.  
차이는 C++은 **메모리 영역과 접근 권한을 직접 제어**한다는 점이다.

---

## 정리 — 이 순서로 이해하면 된다

```
관련 변수들을 묶고 싶다
    → struct (데이터 묶음)
        → struct 안에 함수 추가 (데이터 + 기능)
            → class로 발전 (접근 제어 추가)
                → OOP (캡슐화, 상속, 다형성)
```
