# 4.2 전역 변수(Global Variable), 정적 변수(Static Variable), 내부 연결(Internal Linkage), 외부 연결(External Linkage)

> 전역 변수는 가급적 사용을 안해야 한다.

```cpp
int g_x; // external linkage (초기화가 안된 전역 변수)
static int g_x; // internal linkage (다른 cpp 파일들에서 이 g_x 변수를 접근할 수 없다, 초기화가 안된 정적 변수)
const int g_x;  //! 동작하지 않음 왜냐면 const 변수는 기본적으로 초기화가 반드시 필요하기 때문
const int g_x = 1; // 동작

extern int g_z; // forward declaration
extern const int g_z;   //! 다른 곳 어디선가는 g_z 값을 초기화 해야 함

int g_y(1);
static int g_y(1);  // 다른 cpp 파일에서는 접근 불가능
const int g_y(1);   // 상수 선언

extern int g_w(1);  // 초기화, 전역 변수, 다른 cpp 파일에서도 접근 가능 !초기화를 하면 다른 곳에서는 초기화를 하면 안된다
extern const int g_w(1) // 초기화, 상수, 외부에서도 접근 가능
```

## 1. 전역 변수 (Global Variable)

> 함수 밖에 선언된 변수, 프로그램 어디서든 접근 가능하다

```cpp
#include <iostream>
using namespace std;

int g_apple = 5;    // 전역 변수 (관례상 g_ (global) 접두사 사용)

void doSomething() {
    // int a = 1;   // 매번 1로 초기화
    g_apple += 1;
    cout << g_apple << endl;    // 6
}

int main()
{
    cout << g_apple << endl;    // 5
    doSomething();
    cout << g_apple << endl;    // 6
}
```

### 지역 변수 vs 전역 변수

```cpp
int a = 1;      // 전역 변수

int main()
{
    int a = 2;
    cout << a << endl;      // 2 <- 지역 변수 우선
    cout << ::a << endl;    // 1 <- :: 붙이면 전역 변수 접근
}
```

## 2. 정적 변수 (Static Variable)

> `static` 키워드를 붙이면 함수가 끝나고 값이 유지된다

```cpp
void doSomething() {
    static int a = 1;   // 처음 한 번만 초기화
    a += 1;
    cout << a << endl;
}

int main()
{
    doSomething();  // 2
    doSomething();  // 3
    doSomething();  // 4
}
```

## 3. 내부 연결 (Internal Linkage)

> `static`을 전역 변수에 붙이면 같은 파일 안에서만 접근 가능

> Internal Linkage = 자기 파일 안에서만 사용, 다른 파일에서 접근 X

```cpp
// a.cpp
static int g_a = 1; // 이 파일 안에서만 사용 가능

// b.cpp
extern int g_a;     // 접근 불가
```

## 4. 외부 연결 (External Linkage)

> `extern` 키워드로 다른 파일의 변수/함수를 가져와서 사용 가능

```cpp
// a.cpp
int g_a = 1;
```

## TIP

### 헤더 파일에 네임스페이스 생성

> 이름 충돌 방지 때문에 헤더 파일에 네임스페이스를 사용

- 이름 충돌 방지
- 상수들을 논리적으로 그룹화
- 코드 가독성 향상

#### 문제 상황 (namespace 없을 때)

```cpp
// constants.h
const double PI = 3.14159;  // ❌ 충돌! 같은 이름

// math.h
const double PI = 3.14159;  // ❌ 충돌! 같은 이름
```

```cpp
#include "constants.h"
#include "math.h"       // 컴파일 에러: PI가 이미 존재
```

#### 해결

```cpp
// constants.h
namespace Constants {
    const double PI = 3.14159;
}

// math.h
namespace Math {
    const double PI = 3.14159;
}

Constants::PI   // 3.14159
Math::PI   // 3.14159
```

#### 헤더 파일을 만들고, 헤더 파일의 변수를 여러 cpp 파일에서 호출할 때 주소 값이 다르다

```cpp
// constants.h
namespace Constants {
    const double pi = 3.141592; // 각 .cpp에서 include 하면 복사본 생성
}
```

- main.cpp와 external_variable.cpp가 각각 자기만의 pi를 가짐 -> 주소가 다름

```cpp
// constants.cpp
namespace Constants {
    extern const double pi = 3.141592;  // 딱 한 번만 정의
}
```

- 모든 파일이 `constants.cpp`의 변수 하나를 공유 -> 주소 동일
- 추가로 알아두면 좋은 점 
    - C++에서 `const` 변수는 기본적으로 내부 연결 (internal linkage)
    - 그래서 헤더에 `const double pi = 3.141592`를 쓰면 include한 파일마다 복사본이 생기는 거고, `extern`을 명시하면 외부 연결(external linkage)로 바뀌어서 단 하나의 정의를 전체가 공유하게 됩니다
