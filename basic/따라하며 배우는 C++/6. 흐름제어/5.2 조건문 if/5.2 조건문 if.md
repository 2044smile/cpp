# 5.2 조건문 if

## if

```cpp
if (x > 10)
    cout << x << " is greater than 10" endl;
    cout << "Test" << endl; // 에러 발생

if (x > 10)
{   // 중괄호 필수
    cout << x << " is greater than 10" endl;
    cout << "Test" << endl; // 정상 작동
}
```

## 부정형 if

```cpp
if (!(x >= 20)) // ! 연산자로 전체 부정
```

```python
if not (x >= 20)
```

## 실수

```cpp
int x;
cin >> x; // 10

if (x = 0) // x = 0, False
```
