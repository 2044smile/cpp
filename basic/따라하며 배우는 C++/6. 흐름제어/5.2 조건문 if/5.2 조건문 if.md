# 5.2 조건문 if

---

## 1. 기본 if / else

```cpp
if (x > 10)
{
    cout << x << " is greater than 10" << endl;
    cout << "Test" << endl;
}
else
    cout << x << " is not greater than 10" << endl;
```

### 중괄호 주의

```cpp
// 중괄호 없이 2줄 — 두 번째 줄은 if와 무관하게 항상 실행됨
if (x > 10)
    cout << x << " is greater than 10" << endl;
    cout << "Test" << endl;  // 항상 실행 (버그!)

// 중괄호로 묶어야 if 블록에 포함됨
if (x > 10)
{
    cout << x << " is greater than 10" << endl;
    cout << "Test" << endl;  // x > 10 일 때만 실행
}
```

> 실행할 문장이 한 줄이어도 **중괄호를 쓰는 습관**을 들이면 이런 실수를 방지할 수 있습니다.

## 2. 조건에 정수 리터럴 사용

```cpp
if (1)   // 1 = true, 항상 실행
if (0)   // 0 = false, 절대 실행 안 됨
```

C++에서 조건식은 **0이면 false, 0이 아니면 true**입니다.

---

## 3. if 블록 안의 지역 변수 스코프

```cpp
int x;
cin >> x;   // 바깥 x

if (1)
    int x = 5;  // 새로운 지역변수 x — 바깥 x와 별개, 블록 종료 시 소멸
else
    int x = 6;

cout << x << endl;  // 바깥 x 출력 (입력값 그대로)
```

- `int x = 5`는 바깥 `x`를 수정하는 게 아니라 **새 변수를 선언**한 것
- if 블록을 벗어나는 순간 안쪽 `x`는 **소멸**됨
- `cout << x`는 바깥 `x`(입력값)를 출력

## 4. Chaining — else if 연결

여러 조건을 순서대로 검사하고, **하나만 실행되면 나머지는 건너뜁니다.**

```cpp
if (x > 10)
    cout << "x is greater than 10" << endl;
else if (x < 10)
    cout << "x is less than 10" << endl;
else            // 위 조건이 모두 거짓 → 논리적으로 x == 10 보장
    cout << "x is exactly 10" << endl;
```

### if 따로 vs chaining 비교

```cpp
// if 따로 — 3개 조건 모두 검사
if (x > 10) cout << "greater" << endl;
if (x < 10) cout << "less" << endl;
if (x == 10) cout << "exactly" << endl;

// chaining — 참인 블록 하나만 실행, 나머지 건너뜀
if (x > 10)       cout << "greater" << endl;
else if (x < 10)  cout << "less" << endl;
else              cout << "exactly" << endl;
```

조건이 **서로 배타적**일 때는 반드시 chaining을 사용하세요.

## 5. 중첩 if (Nested if)

```cpp
if (x >= 10)
{
    if (x >= 20)
        cout << x << " is between 10 and 20" << endl;
    else
        cout << "..." << endl;
}
```

if 안에 if를 넣을 수 있습니다. 단, **깊이가 깊어질수록 가독성이 떨어지므로** 3단계 이상 중첩은 피하는 것이 좋습니다.

---

## 6. 논리 연산자

```cpp
if (i > 0 && j > 0)        // AND: 둘 다 참일 때
    cout << "both positive" << endl;
else if (i > 0 || j > 0)   // OR: 하나라도 참일 때
    cout << "one is positive" << endl;
else
    cout << "neither is positive" << endl;
```

| 연산자 | 의미 | 참이 되는 조건 |
|---|---|---|
| `&&` | AND | 양쪽 모두 참 |
| `\|\|` | OR | 하나라도 참 |
| `!` | NOT | 조건을 반전 |

### 부정형

```cpp
if (!(x >= 20))   // x < 20 과 동일
```

```python
# Python
if not (x >= 20):
```

## 7. if 안에서 return — 조기 종료

```cpp
if (q == -1)
{
    cout << "종료" << endl;
    return 0;   // main() 즉시 종료
}
```

특정 조건에서 함수(또는 `main`)를 **즉시 종료**할 수 있습니다.  
이를 **조기 반환(early return)** 이라고 하며, 예외적인 경우를 먼저 처리하고 나머지 로직을 깔끔하게 유지하는 데 유용합니다.

## 8. 삼항 연산자 (Ternary Operator)

```cpp
// if/else 버전
int min(int x, int y)
{
    if (x > y) return y;
    else return x;
}

// 삼항 연산자로 축약
int min(int x, int y)
{
    return (x > y) ? x : y;
}
```

문법:

```
(조건) ? 참일 때 값 : 거짓일 때 값
```

간단한 if/else를 **한 줄로** 표현할 때 사용합니다.  
단, 복잡한 로직에 남용하면 오히려 가독성이 떨어지므로 **단순한 값 선택**에만 쓰는 것이 좋습니다.

---

## 실수 — `=` vs `==`

```cpp
if (x = 0)   // 대입 연산자 — x에 0을 넣고, 0(false)으로 평가 → 항상 false
if (x == 0)  // 비교 연산자 — x가 0인지 비교 (의도한 코드)
```

`=`와 `==`를 혼동하는 것은 C++에서 가장 흔한 실수 중 하나입니다.  
컴파일러가 경고를 내주기도 하지만 오류가 아니라 **그냥 실행**되기 때문에 찾기 어렵습니다.

## 핵심 정리

| 개념 | 내용 |
|---|---|
| 중괄호 | 실행 문장이 2줄 이상이면 필수, 1줄도 습관적으로 쓰기 권장 |
| 0 / 1 | 조건식에서 0 = false, 나머지 = true |
| Chaining | 조건이 배타적일 때 `else if`로 연결 |
| 중첩 if | 3단계 이상 중첩은 가독성 저하 |
| 논리 연산자 | `&&` (AND), `\|\|` (OR), `!` (NOT) |
| 조기 반환 | `if` 안에서 `return`으로 즉시 종료 |
| 삼항 연산자 | `(조건) ? 참 : 거짓` — 단순 값 선택에만 사용 |
| `=` vs `==` | 대입 vs 비교, 혼동 주의 |
