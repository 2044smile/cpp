# 5.1 제어 흐름 개요 Control flow

---

## 들어가며

프로그램은 기본적으로 위에서 아래로 **순서대로** 실행됩니다.  
하지만 현실의 문제를 풀려면 "조건에 따라 다른 동작을 하거나", "같은 작업을 반복하거나", "특정 상황에서 즉시 멈추는" 등의 흐름 제어가 필요합니다.

---

## 순서도 Flow Chart — 제어 흐름의 종류

| 종류 | 키워드 | 설명 |
|---|---|---|
| **중단** (Halt) | `exit()`, `abort()`, `terminate()` | 프로그램을 즉시 종료 |
| **점프** (Jump) | `goto`, `break`, `continue` | 실행 위치를 강제로 이동 |
| **조건 분기** (Conditional branches) | `if`, `switch` | 조건에 따라 다른 코드 실행 |
| **반복** (Loops) | `while`, `do while`, `for` | 조건이 참인 동안 반복 실행 |
| **예외 처리** (Exceptions) | `try`, `catch`, `throw` | 오류 상황을 안전하게 처리 |

---

## 중단 (Halt)

중단이란 **프로그램의 실행을 즉시 멈추는 것**입니다.  
`return 0;`처럼 `main()`이 정상적으로 끝나는 것과 달리, 중단 함수는 **현재 위치에서 즉시 종료**시킵니다.

### `exit()` — 정상 종료

```cpp
#include <iostream>

int main()
{
    std::cout << "I love you " << std::endl;
    exit(0);                                    // 여기서 즉시 종료
    std::cout << "I love you, too" << std::endl; // 절대 실행되지 않음
    return 0;
}
```

실행 결과:
```
I love you
```

`exit(0)` 이후의 코드는 **절대 실행되지 않습니다.**

### `exit()`의 동작 과정

`exit()`은 단순히 "끄는" 게 아니라 정리 작업을 수행합니다.

```
exit() 호출
  │
  ├─ 1. atexit()로 등록된 함수들을 역순으로 실행
  ├─ 2. 전역/정적 객체의 소멸자 호출
  ├─ 3. 열려있는 파일 버퍼 flush 및 닫기
  └─ 4. OS에 종료 코드 반환
```

### 종료 코드 (Exit Code)

```cpp
exit(0);   // 정상 종료 — "프로그램이 성공적으로 끝났다"
exit(1);   // 비정상 종료 — "오류가 있었다"
```

| 종료 코드 | 의미 | 매크로 |
|---|---|---|
| `0` | 성공 | `EXIT_SUCCESS` |
| `1` (또는 그 외) | 실패/오류 | `EXIT_FAILURE` |

```cpp
#include <cstdlib>  // EXIT_SUCCESS, EXIT_FAILURE 사용 시 필요

exit(EXIT_SUCCESS);  // 0과 동일, 더 명확한 표현
exit(EXIT_FAILURE);  // 1과 동일
```

---

## `exit()` vs `return 0` — 무슨 차이?

| 구분 | `return 0` | `exit(0)` |
|---|---|---|
| 위치 | `main()` 함수 끝에서만 의미 있음 | 코드 어디서든 호출 가능 |
| 지역 변수 소멸자 | 호출됨 (스택 정리) | **호출되지 않음** |
| 전역 객체 소멸자 | 호출됨 | 호출됨 |
| 파일 닫기 | 됨 | 됨 |

> **주의** : `exit()`은 현재 스코프의 **지역 변수 소멸자를 건너뜁니다.**  
> 동적 할당 메모리나 파일 핸들을 직접 관리하는 코드에서 `exit()`을 부르면 리소스가 제대로 정리되지 않을 수 있습니다.

---

## 핵심 정리

- `exit(0)` 은 호출된 **그 자리에서 즉시 프로그램을 종료**합니다.
- 이후 코드는 절대 실행되지 않으므로, 중요한 정리 로직이 뒤에 있다면 실행되지 않음을 주의하세요.
- 일반적인 종료는 `return 0`을, 함수 중간에서 프로그램 전체를 멈춰야 할 때는 `exit()`을 사용합니다.
